# Heritage Apple Cultivar Recognition

This repository is the public reproducibility landing page for the article:

**Controlled Multi-View Imaging for Heritage Apple Cultivar Recognition: Comparing Expert Descriptors and Image Encoders**

Anna Wróbel, Giovanni A. L. Broggini, Andi Schmid, Martin Řeřábek, Yulia Sandamirskaya, and Thomas Ott

**Smart Agricultural Technology**, 2026  
Article DOI: [https://doi.org/10.1016/j.atech.2026.102417](https://doi.org/10.1016/j.atech.2026.102417)

## Repository scope

This repository supports the main **Loc_1 2021 38-class comparative evaluation** reported in the paper.

It is intended as a public reproducibility package for the released analysis subset. It is not a release of the complete raw Harvest Set.

The repository contains, or will link to, the released image subset, segmentation outputs, metadata, extracted feature tables, split definitions, saved predictions, and analysis files needed to reproduce the reported aggregate metrics.

## Data availability

The public reproducibility package supporting the main **Loc_1 2021 38-class comparative evaluation** is available in this repository:

[https://github.com/wrob-zhaw/heritage-apple-cultivar-recognition](https://github.com/wrob-zhaw/heritage-apple-cultivar-recognition)

Large image and mask files are hosted separately and will be linked from this repository once the archive is finalized.

The complete raw Harvest Set is not included in the public release due to file-size and curation constraints. It may be made available by the corresponding author upon reasonable request, subject to institutional and project-partner constraints.

Additional project-specific training code is not publicly released where it is subject to project-partner agreements, but may be made available upon reasonable request where permitted.

## Planned contents

The public reproducibility package is planned to include:

- metadata for the public Loc_1 2021 38-class evaluation subset
- class-label information
- split definitions
- extracted expert-feature tables
- saved model predictions
- scripts for reproducing reported aggregate metrics
- access instructions for the released image subset and segmentation outputs

## Status

This repository has been created for the paper release and is currently being populated with the final reproducibility files.

A release version will be created after the repository contents, external data links, and metric-reproduction scripts have been checked.
